## 🎬 Main project

**[FactReel](https://github.com/DeadY2J/factreel)**: open-source Python tool that turns a list of verified facts into faceless Shorts. The AI writes the script, but guards written in code reject any number or claim that isn't in your facts. Free by default, with fallbacks for voice and images.

`pip install factreel` · [Issues to start with](https://github.com/DeadY2J/factreel/issues)
